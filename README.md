# 🔐 CYPHER_TEXT

CYPHER_TEXT is a Python-based cryptography project that demonstrates how classical cipher techniques work, with a primary focus on the **Caesar Cipher**.  
The project is designed for learning, experimentation, and understanding the fundamentals of encryption and decryption.

---

## 📌 Features

- 🔁 Encrypt text using Caesar Cipher
- 🔓 Decrypt encrypted messages
- 🔢 Supports custom shift values
- 🔡 Handles lowercase and uppercase characters
- 🧠 Beginner-friendly implementation
- 🧪 Ideal for cryptography & Python practice

---

## 🛠️ Technologies Used

- **Python 3**
- Basic mathematical logic
- String manipulation
